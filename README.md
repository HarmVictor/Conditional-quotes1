# Mood Selector Program

## 🧠 Project Overview
This is a simple program that asks the user:

> **"How is your day going?"**

The user can select one of three moods:
- **Not so great**
- **So-so**
- **Great**

Based on the selection, the program will display a corresponding image that is stored in a folder linked to that mood.

## 🎯 Features
- Mood selection UI (Not so great / So-so / Great)
- Displays a mood-specific image upon selection
- Organized folder structure for mood-based images

## 📁 Folder Structure
```
/project-root
  /not_so_great/
    - sad_image1.jpg
  /so_so/
    - neutral_image1.jpg
  /great/
    - happy_image1.jpg
  main.py
  README.md
```

## 🚀 How to Use
1. Run the program (e.g., using `python main.py`).
2. You'll be asked: **"How is your day going?"**
3. Choose one of the moods.
4. A matching image will be shown based on your selection.
